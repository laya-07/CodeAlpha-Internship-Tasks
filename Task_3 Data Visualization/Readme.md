# CodeAlpha Task 3 - Data Visualization

## 📊 Project Overview

This project is part of the **CodeAlpha Data Analytics Internship**.

The objective of this task is to transform raw book data into meaningful visualizations using Python. The visualizations help identify patterns and trends in book prices and ratings and present the findings in a clear and understandable way.

## 🎯 Objectives

- Transform raw data into visual formats.
- Create meaningful charts and graphs.
- Analyze book prices and ratings.
- Identify patterns and trends in the dataset.
- Present data insights clearly through visualizations.

## 📁 Dataset

The dataset used in this project is the **Books to Scrape** dataset collected during Task 1.

The dataset contains information about 1,000 books, including:

- Title
- Price
- Rating
- Availability

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## 📊 Visualizations Created

The following visualizations were created:

1. **Price Distribution**
   - Shows the distribution of book prices.

2. **Rating Distribution**
   - Shows the number of books for each rating.

3. **Average Price by Rating**
   - Compares the average book price across different ratings.

4. **Books by Price Range**
   - Shows the number of books within different price ranges.

5. **Top 10 Most Expensive Books**
   - Displays the ten books with the highest prices.

6. **Price vs Rating**
   - Helps examine the relationship between book prices and ratings.

## 🔍 Key Insights

- Book prices are distributed across different price ranges.
- All five rating categories are represented in the dataset.
- The average price varies across different rating categories.
- Most books fall within the middle price ranges.
- A small number of books have relatively higher prices.
- The Price vs Rating visualization helps identify whether book ratings have a noticeable relationship with their prices.
