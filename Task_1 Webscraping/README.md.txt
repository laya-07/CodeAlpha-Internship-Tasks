# CodeAlpha Internship - Task 1: Web Scraping

## Project Description

This project was developed as part of the CodeAlpha Data Analytics Internship.

The objective of this project is to scrape book information from the "Books to Scrape" website using Python and BeautifulSoup.

## Website

https://books.toscrape.com/

## Technologies Used

- Python
- Requests
- BeautifulSoup
- Pandas

## Data Extracted

- Book Title
- Price
- Rating
- Availability

## Output

The extracted data is stored in a CSV file named **books.csv**.
