# CodeAlpha Internship - Task 2
# Exploratory Data Analysis (EDA)

## Objective

The objective of this project is to perform Exploratory Data Analysis (EDA) on the Books dataset collected during Task 1. The analysis aims to understand the dataset, identify trends and patterns, validate assumptions using statistical analysis, and detect potential data quality issues.

---

## Dataset

- Dataset Name: Books Dataset
- Source: Books to Scrape (https://books.toscrape.com/)
- Total Records: 1000
- Total Columns: 4 (Original Dataset)

Columns:
- Title
- Price
- Rating
- Availability

---

## Libraries Used

- pandas
- numpy
- matplotlib

---

## Project Steps

### Step 1: Ask Meaningful Questions

Prepared analytical questions before exploring the dataset.

Examples:
- What is the average price of books?
- Which rating occurs most frequently?
- Are higher-rated books more expensive?
- Are there any missing values?
- Are there duplicate records?

---

### Step 2: Explore the Data Structure

Performed:
- Dataset preview
- Dataset shape
- Column names
- Data types
- Summary statistics
- Missing value analysis
- Duplicate record detection

---

### Step 3: Identify Trends, Patterns, and Anomalies

Analyzed:
- Price statistics
- Rating distribution
- Average price by rating
- Highest and lowest priced books
- Price range distribution
- Outlier detection using IQR

---

### Step 4: Test Hypotheses and Validate Assumptions

Tested hypotheses using statistical analysis and supporting visualizations.

Examples:
- Relationship between price and rating
- Distribution of book prices
- Presence of outliers
- Distribution of ratings

---

### Step 5: Detect Potential Data Issues

Checked:
- Missing values
- Duplicate records
- Data types
- Invalid price values
- Rating consistency
- Outliers

---

## Key Findings

- Dataset contains 1000 books.
- No missing values were found.
- No duplicate records were detected.
- No invalid price values were identified.
- No outliers were detected using the IQR method.
- Book ratings are unevenly distributed.
- Average book prices are similar across all rating categories.
- The dataset is clean and suitable for further analysis.

---

## Conclusion

The exploratory data analysis successfully examined the Books dataset using statistical techniques. The dataset was found to be clean, consistent, and free from major quality issues. Several useful insights regarding book prices and ratings were identified, providing a solid foundation for further data visualization and analysis.
